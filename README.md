# SharpCut Barbershop Website 💈✂️

A modern, responsive barbershop website built with HTML5, CSS3, JavaScript, and Bootstrap 5. Designed with a luxury black and gold aesthetic.

## 🌟 Features
- **Modern Responsive Design**: Optimized for desktop, tablet, and mobile screens.
- **Black, Gold & White Theme**: Professional, high-end barbershop visual appeal.
- **Interactive Booking Form**: Client-side appointment reservation with instant confirmation.
- **Service Menu**: Priced services with direct booking links.
- **Gallery & Portfolio**: Grid layout displaying fresh cuts and grooming styles.
- **Business Hours & Contact**: Integrated phone call and WhatsApp quick links.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Custom design system & Google Fonts)
- **JavaScript** (Vanilla JS for interactive features)
- **Bootstrap 5 & Font Awesome 6**
